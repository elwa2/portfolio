# ⚙️ ربط متتبع العادات بـ Google Sheets

## 📁 الملفات

| الملف | الوظيفة |
|---|---|
| `Code.gs` | كل دوال الخلفية (القراءة/الكتابة/الإعداد/القائمة) |
| `appsscript.json` | إعدادات المشروع (المانيفست) |

---

## 🛠️ التركيب (مرة واحدة)

### 1. أنشئ ملف Google Sheet جديد
- [sheets.new](https://sheets.new) → سمِّه مثلاً `Habit Tracker 2026`

### 2. افتح محرر Apps Script
- من داخل الـ Sheet: **Extensions → Apps Script**
- ⚠️ **مهم:** امسح أي كود موجود واستبدله بمحتوى `Code.gs`

### 3. فعّل الدالة/setup
- من شريط الأدوات في المحرر اختر دالة **`setupSheets`** واضغط **Run** ▶
- سيطلب أذونات → **Review permissions** → اختر حسابك → **Advanced** → **Go to project (unsafe)** → **Allow**
- المفروض تشوف في الـ Log: `✅ Listo. Tablas...`

> الدالة دي هي اللي **بتعمل الجداول** (Sheets) المطلوبة تلقائيًا:
> - `Habits` → العادات (id, name, icon, sort, active, createdAt)
> - `Daily` → العلامات ✓ (habitId, month, day, done, updatedAt)
> - `Meta` → إعدادات (schemaVersion, sheetId, …)
> - `لوحة التحكم` → **صفحة جديدة** فيها ملخصات +.formulas بتتحدث لوحدها + دليل الكتابة اليدوية
>
> وبتضيف **7 عادات جاهزة** لو الجدول فاضي، و**dropdowns** (قوائم اختيار) في الأعمدة المهمة
> عشان الكتابة اليدوية ما تعملش بيانات غلط.
>
> ℹ️ بعد التثبيت هتلاقي في الـ Sheet قائمة **⚙️ متتبع العادات** فيها:
> - `📊 فتح لوحة التحكم`
> - `🛠 تهيئة / إصلاح الجداول`
> - `ℹ️ عرض معرّف السبيتش شيت`
> - `📊 تقرير سريع`
> - `🗑 مسح كل العلامات`

### 4. انسخ الـ Spreadsheet ID
- من صفحة الـ Sheet: الرابط مثل
  `https://docs.google.com/spreadsheets/d/`**`1AbCd...XYZ`**`/edit`
  الـ **ID** هو الجزء بين `/d/` و `/edit`
- حطّه في أول سطر من `Code.gs`:
  ```javascript
  var SPREADSHEET_ID = '1AbCd...XYZ';
  ```
  (لو الـ Script مرتبط بالـ Sheet نفسه ممكن تسيبه فاضي)

### 5. انشره Web App
- **Deploy → New deployment → ➕ → Web app**
- **Execute as:** `Me` (أنت)
- **Who has access:** `Anyone` (أو `Anyone with Google account`)

  > هذا الإعداد **مطلوب** عشان المتصفح يقدر يقرأ ويكتب من الـ Web App.
  > (لو حبيت تقيّده، استخدم `Anyone with Google account` بدل `Anyone`.)

- اضغط **Deploy** وامنح الأذونات → انسخ **Web App URL**

### 6. الصق الرابط في الأداة
- افتح `habit-tracker.html` ← قسم **«☁️ Google Sheets»**
- الصق الـ **Web App URL** في خانة **رابط السكربت**
- اضغط **💾 حفظ** ثم **🔄 مزامنة**

## 🔗 الدوال المتاحة في `Code.gs`

| الدالة | النوع | الوظيفة |
|---|---|---|
| `setupSheets()` | دالة رئيسية | تنشئ/تصلح كل الجداول + لوحة التحكم + تضيف العادات الافتراضية |
| `showDashboard()` | قائمة | تفتح/تعيد بناء ورقة `لوحة التحكم` (**الصفحة الجديدة**) |
| `buildDashboard_()` | داخلية | تبني لوحة التحكم (ملخصات +.formulas + دليل) |
| `onOpen()` | تلقائي | يظهر قائمة `⚙️ متتبع العادات` جوه الـ Sheet |
| `doGet(e)` | Web API | قراءة: `?action=getAll` / `getHabits` / `getMonth&month=8` / `info` / `setup` |
| `doPost(e)` | Web API | كتابة + قراءة (انظر تحت) |
| `showSpreadsheetId()` | قائمة | يعرض الـ Spreadsheet ID + الرابط |
| `quickReport()` | قائمة | تقرير سريع (عدد العادات، الإجمالي، أفضل عادة) |
| `clearChecksPrompt()` | قائمة | يمسح كل العلامات (بتأكيد) |
| `testSetup()` | اختبار | ينفّذ الـ setup ويطبع Log |

### `doPost` بيقبل الكتابة والقراءة
> **ليه القراءة عن طريق POST؟** لأن طلب `POST` بـ `Content-Type: text/plain` هو
> *simple request* ما بيعملش **preflight**، فبيشتغل بثبات من المتصفح (حتى من `file://`).
> أمّا `GET` بيعتمد على إعادة التوجيه (redirect 302) بتاعت Apps Script،
> وممكن تحصل مشاكل في بعض المتصفحات.
> عشان كده الأداة بتحاول **POST الأول** وبعدين **GET** كـ plan B.

| `action` | الوظيفة |
|---|---|
| `import` | **الاستيراد**: يرجّع العادات + العلامات + **ملخص** (`summary`) |
| `getAll` | يرجّع العادات + العلامات + الميتا |
| `getMonth` | يرجّع علامات شهر واحد (`month`) |
| `info` | معلومات الـ Sheet |
| `setup` | ينفّذ `setupSheets()` (إنشاء كل الجداول) |
| `dashboard` | يعيد بناء ورقة `لوحة التحكم` |
| `saveAll` | يحفظ العادات + العلامات (المزامنة الكاملة) |
| `saveHabits` | يحفظ العادات فقط |
| `saveChecks` | يحفظ العلامات فقط |
| `clearChecks` | يمسح كل العلامات |

### أمثلة GET (لو حبيت تستخدمها)
```
…/exec?action=info          → معلومات الـ Sheet وعدد الصفوف
…/exec?action=getHabits     → قائمة العادات
…/exec?action=getMonth&month=8  → علامات شهر سبتمبر
```

### أمثلة على POST (body JSON)
```json
{ "action": "getAll" }
{ "action": "saveAll", "habits": [...], "checks": {"h1|8|1": 1} }
```

## 🗂️ بنية البيانات

### جدول `Habits`
| id | name | icon | sort | active | createdAt |
|---|---|---|---|---|---|
| h1 | استيقاظ 5:00 | ⏰ | 1 | TRUE | 2026-09-26 14:00:00 |

### جدول `Daily` (صف لكل علامة ✓)
| habitId | month | day | done | updatedAt |
|---|---|---|---|---|
| h1 | 8 | 1 | TRUE | 2026-09-26 14:00:00 |

> `month` = رقم الشهر (**0** = يناير … **11** = ديسمبر)، `day` = 1..31

### جدول `Meta`
| key | value |
|---|---|
| schemaVersion | 1 |
| sheetId | 1AbCd... |
| setupAt | 2026-09-26 14:00:00 |

### جدول `لوحة التحكم` (الصفحة الجديدة)
| الخانة | المحتوى |
|---|---|
| عدد العادات | `COUNTA` من جدول Habits |
| إجمالي العلامات ✓ | `COUNTIF` على جدول Daily |
| نسبة الإنجاز الكلية | نسبة مئوية |
| جدول لكل عادة | **.formulas `COUNTIFS`** بتتحسب لوحدها |
| ✍️ دليل الكتابة اليدوية | شرح مختصر/rules قبل الجداول |

## ✍️ اكتب في الـ Sheet مباشرة واستورد (الـ Sheet = قاعدة بيانات)

> الفكرة: **الـ Google Sheet هو المصدر الحقيقي**، وأنت تقدر تعدّل فيه بأي شكل
> (من المتصفح أو من Excel) والموقع يستورد تعديلاتك بضغطة واحدة.

### ١) في جدول `Habits`
- اكتب **اسم العادة** في عمود `name` — عمود `id` **اختياري**، لو تركته فاضي
  الـ id هيتولّد تلقائيًا من الاسم.
- عمود `icon`: اختياري (الإيموجي).
- عمود `active`: `TRUE` للعادة المفعّلة، `FALSE` لإيقافها (فاضي = مفعّلة).

### ٢) في جدول `Daily`
| العمود | اكتب فيه | أمثلة مقبولة |
|---|---|---|
| `habitId` | **اسم العادة أو الـ id** | `قراءة 10 صفحات` أو `h6` |
| `month` | رقم الشهر **0..11** أو اسم الشهر | `0`, `8`, `سبتمبر` |
| `day` | رقم اليوم 1..31 | `15` |
| `done` | القيمة | `TRUE`, `✓`, `نعم`, `1`, `X` |

> ⚠️ لو كتبت اسم شهر أو id مش موجود، السطر **يتجاهل** بدل ما يكسر البيانات.

### ٣) بعد الكتابة — استورد
- **⬇️ استيراد من Sheets** في الأداة، أو
- **استيراد عند الفتح** (مفعّل افتراضيًا) — بيحصل تلقائيًا كل ما تفتح الصفحة، أو
- **من ملف Excel**: انسخ الصفوف، الصقها في
  «📥 استيراد من ملف Excel (نسخ ولصق)» داخل الأداة:
  ```
  قراءة 10 صفحات	📚	TRUE
  جيم ساعة	🏋️	TRUE
  قراءة 10 صفحات|8|15
  ```
  - سطر بـ 3 خانات ورقم شهر + يوم صحيح = **علامة** ✓
  - أي سطر تاني = **عادة** (اسم + أيقونة اختيارية + مفعّل اختياري)

## 📅 تمييز اليوم وقفل الأيام المستقبلية

الأداة بتحسب حالة كل يوم أوتوماتيك من التاريخ الحقيقي:

| الحالة | الشرط | في الجدول |
|---|---|---|
| **ماضٍ** | قبل النهارده | ✅ قابل للتعديل عادي |
| **اليوم** | نهارده بالظبط | 🔵 عمود/صف مميّز + قابل للتعليم |
| **مستقبلي** | بعد النهارده أو أي شهر بعده | 🔒 مقفول — مش قابل للتعديل |

- 🎯 **عمود النهارده** عليه خط وتوهّج أزرق، وكل خانة فيه بإطار مميّز.
- 🔒 **الأيام الجاية** شكلها باهت بخط متقطّع + علامة قفل، والنقر عليها يعمل toast: «يوم مستقبلي — مش قابل للتعديل».
- 🛡️ الحماية **مزدوجة**: الخانة `disabled` في الـ HTML + وحاجز داخل `setCheck()` و`toggleCell()`، فمفيش طريقة تفتحها حتى لو عدّلت من الـ console.
- ⚠️ الشهور السابقة **كلها** قابلة للتعديل، والشهور الجاية **كلها** مقفولة.
- 🧹 زر **«اليوم»** السريع في قائمة العادات بيشتغل عادي لأنه بيمسح نهارده تحديدًا.

> لو استوردت علامات لأيام مستقبلية من الـ Sheet، هتظهر مكتملة بس مقفولة —
> لأن الاستيراد بيحافظ على كل بيانات الـ Sheet كما هي.

## 🔁 كيف المزامنة شغالة في الأداة

- **💾 حفظ محلي** — يخزن في `localStorage` (offline-first، شغال دايمًا)
- **⬆️ تصدير إلى Sheets** — يبعت العادات + العلامات للـ Sheet
- **⬇️ استيراد من Sheets** — يجيب كل ما هو مكتوب في الـ Sheet ويحدّث الشاشة
- **🔄 مزامنة** — تصدير + استيراد
- **⬇️ استيراد عند الفتح** — تلقائي كل مرة تفتح الصفحة (مفعّل افتراضيًا)
- **⬆️ رفع تلقائي** — كل ما تعدّل عادة أو علامة، ترفع تلقائيًا (لو مفعّل)
- **📥 استيراد من Excel** — نسخ/لصق من أي ملف Excel

> `localStorage` يفضل كـ cache حتى لو الـ Sheet مش متاح، فمفيش بيانات تضيع.
> لو الاستيراد رجّع 0 عادات، الأداة **بتحافظ** على عاداتك المحلية بدل ما تمسحها.
