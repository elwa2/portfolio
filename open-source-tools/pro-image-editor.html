Artboards

How it works: the document is the board — it is bigger than the artboard, so you can add several images as layers and freely move them outside the artboard. When you Export, only the pixels inside the selected artboard are saved. Use the Artboard Tool (A) on the left toolbar — drag to create a new artboard, drag an artboard to move it, drag its corners to resize it.

About PhotoForge

PF
PhotoForge — Pro Image Editor
Version 2.0 — a generator-class tool from the Generative Tools showcase.
Works offline
PhotoForge runs fully in your browser and uses no network for image editing. PDF & JsPDF libraries are bundled locally first, with a CDN fallback — so everything keeps working even when the internet is disconnected.
What's new in 2.0
Folder drop — drop a whole folder, every image opens in its own tab
Save All JPG / PNG — one folder, every open tab saved; JPG uses a unified quality chooser
Close All + per-tab state; shortcuts modal from the menu
Stability — serialized loading, tab-aware rendering, safe exports
PDF — local-first PDF.js, page navigation, combined PDF export
Offline — no internet needed after first load of libraries
